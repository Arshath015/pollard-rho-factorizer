# Case Study: Using Pollard's Rho Algorithm for Integer Factorization
## Introduction
This case study demonstrates the usage of Pollard's rho algorithm for integer factorization. The algorithm is implemented in the `core/pollard_rho.py` module.
## Results
The algorithm was tested on several numbers, including small and large numbers, and prime numbers. The results are presented in the following table:
| Number | Factors |
| --- | --- |
| 10 | [2, 5] |
| 15 | [3, 5] |
| 8051 | [97, 83] |
| 23 | None |
## Conclusion
The results demonstrate that the algorithm is effective in factoring integers using Pollard's rho algorithm.

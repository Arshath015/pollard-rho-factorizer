## Theoretical Background
Pollard's rho algorithm is a popular integer factorization algorithm. It works by finding a cycle in the sequence generated by the function f(x) = (x^2 + c) mod n, where n is the number to be factored and c is a constant.
This algorithm has a time complexity of O(√p), where p is the smallest prime factor of n.

## Usage
To use this submodule, make a POST request to the /factor endpoint with the number to be factored in the request body.
## API Reference
* `PollardRho.factor(n: int) -> List[int]`: Factors the given number using Pollard's rho algorithm.
* `Utils.is_prime(n: int) -> bool`: Checks if the given number is prime.
